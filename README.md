# ציור ביום: הוראות התקנה

האפליקציה היא אתר שמותקן על מסך הבית (PWA). היא מורכבת משני חלקים חינמיים:
- **Supabase** שומר את הציורים, את החשבונות ואת התגובות.
- **GitHub Pages** מגיש את האתר.

ההתקנה לוקחת בערך 15 דקות ורק פעם אחת.

## שלב 1: חשבון ופרויקט ב-Supabase

1. נכנסים ל-supabase.com ופותחים חשבון (אפשר להתחבר עם GitHub).
2. לוחצים **New project**. נותנים שם (למשל `drawing-a-day`), בוחרים סיסמה לבסיס הנתונים ושומרים אותה, ובוחרים אזור קרוב (Frankfurt או London).
3. מחכים כדקה וחצי עד שהפרויקט מוכן.

## שלב 2: יצירת הטבלאות וההרשאות

1. בתפריט הצד של Supabase נכנסים ל-**SQL Editor**.
2. פותחים את הקובץ `supabase-setup.sql` מהתיקייה הזו, מעתיקים את כולו, מדביקים ולוחצים **Run**.
3. אמורה להופיע הודעת הצלחה (Success. No rows returned). אם יש שגיאה, מעתיקים אותה אליי ואתקן.

## שלב 3: כיבוי אישור אימייל

כדי שהרשמה תעבוד מיד, בלי מייל אישור:

1. נכנסים ל-**Authentication**, ואחר כך ל-**Sign In / Providers** (או Providers).
2. פותחים את **Email** ומכבים את **Confirm email**. שומרים.

## שלב 4: העתקת שני הערכים

1. נכנסים ל-**Project Settings**, ואחר כך ל-**API** (או API Keys).
2. מעתיקים את **Project URL**.
3. מעתיקים את המפתח הציבורי: **anon public** (במסכים חדשים הוא נקרא **publishable key**).
4. פותחים את הקובץ `config.js` ומחליפים את `YOUR_SUPABASE_URL` ואת `YOUR_SUPABASE_ANON_KEY`. משאירים את המירכאות.
5. בשורה `START_DATE` כתוב היום הראשון של המחברת. עכשיו זה `2026-08-26`. אם זה לא נכון, מתקנים.

המפתח הזה נועד להיות גלוי באתר. ההגנה על הנתונים היא ההרשאות מהשלב 2.

## שלב 5: העלאה ל-GitHub Pages

1. ב-GitHub לוחצים **New repository**, נותנים שם (למשל `drawing-a-day`) ובוחרים **Public**. GitHub Pages בחשבון חינמי עובד רק עם מאגר ציבורי.
2. לוחצים **uploading an existing file**, וגוררים פנימה את **כל התוכן** של התיקייה (הקבצים והתיקייה `icons`, לא את התיקייה עצמה). לוחצים **Commit changes**.
3. נכנסים ל-**Settings**, ואחר כך ל-**Pages**. תחת Source בוחרים **Deploy from a branch**, ענף **main** ותיקייה **/ (root)**, ולוחצים Save.
4. אחרי כדקה הכתובת מופיעה בראש העמוד: `https://השם-שלך.github.io/drawing-a-day/`

## שלב 6: התקנה באייפון

1. פותחים את הכתובת ב-**Safari** (חייב Safari, לא Chrome).
2. לוחצים על כפתור השיתוף (ריבוע עם חץ) ובוחרים **Add to Home Screen**.
3. פותחים את האפליקציה מהאייקון שעל מסך הבית.
4. **נרשמים או מתחברים מתוך האפליקציה שנפתחה מהאייקון.** האפליקציה שבמסך הבית לא חולקת התחברות עם Safari, ולכן צריך להיכנס שוב בתוכה פעם אחת.

באנדרואיד: ב-Chrome, תפריט ואז **Install app**.

## שלב 7: נרשמים שניכם

1. כל אחד נרשם עם אימייל, סיסמה ושם.
2. אחרי ששניכם נרשמתם, סוגרים את ההרשמה כדי שאף אחד אחר לא יוכל להצטרף: ב-Supabase, **Authentication**, ואז **Sign In / Providers**, וכיבוי **Allow new users to sign up**.
   (אם תרצו להוסיף מישהו אחר אחר כך, מדליקים אותו שוב.)

## שלב 8: העלאת הציורים הקודמים

1. בעמוד הראשי לוחצים **ציור חדש** ובוחרים את כל התמונות בבת אחת.
2. התמונות מסודרות לפי תאריך. עוברים על התאריכים ומתקנים לפי הצורך.
3. לוחצים **שמירה** ומחכים. ציור שני באותו תאריך מחליף את הקודם.

## דברים טובים לדעת

- **פרויקט Supabase חינמי נעצר אחרי שבוע בלי שימוש.** שימוש יומי מונע את זה. אם נעצר, נכנסים ל-Supabase ולוחצים Restore.
- **המחיר:** חינם. התוכנית החינמית של Supabase כוללת 1GB של קבצים ושומרת כל תמונה בגודל קטן, כך ששנה של ציורים לשניכם נכנסת בה.
- **עדכון האפליקציה:** מחליפים קובץ ב-GitHub. סוגרים את האפליקציה לגמרי ופותחים אותה פעמיים כדי שהגרסה החדשה תיטען.
